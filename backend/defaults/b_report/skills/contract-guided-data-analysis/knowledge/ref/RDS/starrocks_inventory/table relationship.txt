# StarRocks Inventory table relationships
#
# Country schemas are normalized with xx, for example:
#   dw_us.dwd_disty_inv_qty_df -> dw_xx.dwd_disty_inv_qty_df
#   ods_ca.ods_cis_corp_inv_qty_rt -> ods_xx.ods_cis_corp_inv_qty_rt
#
# Base table rules:
#   Use date_flag/current snapshot filters whenever the table has date_flag or *_rt suffix snapshot logic.
#   Prefer inventory fact or inventory ODS table as the driving table, then left join product/order/customer/location dimensions.
#
# Main inventory sources:
#   dw_xx.dwd_disty_inv_qty_df: curated inventory quantity fact.
#   dw_xx.dwd_disty_inv_aging_df: curated inventory aging fact; filter view_level = 'IT_PART' for part-level aging.
#   ods_xx.ods_dw_prod_dws_dw_inv_qty: StarRocks ODS inventory quantity source from DW PROD.
#   ods_xx.ods_cis_corp_inv_qty_rt: CIS real-time/current inventory quantity source.
#   ods_xx.ods_cis_corp_inv_qty: CIS inventory quantity source.
