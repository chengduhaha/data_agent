# Vertica CPO table relationships
#
# Country schemas are normalized with xx, for example:
#   dm_us.dm_disty_sales_open_cpo -> dm_xx.dm_disty_sales_open_cpo
#   ods_ca.ods_cis_corp_cpo_header -> ods_xx.ods_cis_corp_cpo_header
#
# Base table rules:
#   Use CPO DM/fact tables as the driving source for CPO reports.
#   Use ODS CPO/order/history tables only when the report requires attributes not present in the curated CPO facts.
#   Apply date_flag/current snapshot filters whenever a curated DW fact table has date_flag.
