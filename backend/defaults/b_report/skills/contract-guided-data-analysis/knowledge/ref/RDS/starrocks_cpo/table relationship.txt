# StarRocks CPO table relationship reference
#
# Country schemas are normalized with xx in this file.
#
# Scope
#   Generated from StarRocks CPO rds_xxx_rtv.sp scripts identified by matching
#   StarRocks *_gen.sp files that contain tempdb.rds_tmp.
#   Use the CPO header/detail tables as the driving tables for quote/CPO reports.
#   Use order/history tables when a CPO has been converted to sales order or shipped history context.
#   Prefer LEFT JOIN for optional profile, EU custom, address, contact, territory, manager, pipeline, ETA, and service-contract enrichment.
#
# Common grain
#   CPO header grain: cpo_id
#   CPO line grain: cpo_id, cpo_line_seq
#   Order header grain: order_no, order_type
#   Order line grain: order_no, order_type, order_line_no
#   Product grain: sku_no
#   Customer grain: cust_no

# Profile, Expense, SPA, List Box, and Change Log Relationships

ods_xx.ods_cis_corp_cpo_profile_rt is a generic CPO profile table; join by cpo_id and optionally cpo_line_seq, then filter profile_cat, profile_type, active, or profile_no.
ods_xx.ods_cis_corp_history_cpo_profile_rt is the historical CPO profile table; join by cpo_id and optionally cpo_line_seq, then filter profile_cat, profile_type, active, or profile_no.
ods_xx.ods_cis_corp_order_profile_rt is a generic order profile table; join by order_no, order_type and optionally order_line_no, then filter profile_cat, profile_type, active, or profile_no.
ods_xx.ods_cis_corp_history_profile_rt is a generic historical order profile table; join by order_no, order_type and optionally order_line_no, then filter profile_cat, profile_type, active, or profile_no.
ods_xx.ods_cis_corp_order_exp_rt (one to many) ods_xx.ods_cis_corp_order_profile_rt by using join columns order_no, order_type, order_line_no, order_expense_line_no to profile_no when expense profile fields are required

ods_xx.ods_cis_corp_order_profile_rt (many to one) ods_xx.ods_cis_corp_spa_header_rt by using join columns profile_i to spa_no when profile stores SPA reference
ods_xx.ods_cis_corp_cpo_profile_rt (many to one) ods_xx.ods_cis_corp_spa_header_rt by using join columns profile_i or profile_f to spa_no when CPO profile stores SPA reference
ods_xx.ods_cis_corp_list_box_detail_rt is a generic code lookup; join by code_value and filter list_box_code for the required code set such as SKU ABC, customer type, or report-specific list boxes.
ods_xx.ods_cis_corp_change_log_ord (many to one) ods_xx.ods_cis_corp_order_header_rt by using join columns order_no, order_type when current order change-log context is required
ods_xx.ods_cis_corp_history_log_ord (many to one) ods_xx.ods_cis_corp_history_header_rt by using join columns order_no, order_type when historical order change-log context is required
