# Inventory table relationships
#
# Country schemas are normalized with xx, for example:
#   dw_us.dwd_disty_inv_qty_df -> dw_xx.dwd_disty_inv_qty_df
#   dim_ca.dim_pub_part_info   -> dim_xx.dim_pub_part_info
#
# Base table rules:
#   Use date_flag to limit reporting date whenever the table has date_flag.
#   Prefer base inventory fact table left join dimension or supplemental fact tables.
#
# Main inventory grains:
#   dw_xx.dwd_disty_inv_qty_df is at date_flag + loc_no + inv_type + sku_no level.
#   dw_xx.dwd_disty_inv_aging_df is usually at date_flag + inv_type + sku_no + view_level level.
#   For part-level aging reports, filter dw_xx.dwd_disty_inv_aging_df.view_level = 'IT_PART'.
